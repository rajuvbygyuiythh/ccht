■ PART 1 — MOROL BHAB (মূল কথা)
--------------------------------------------------------------------------------
Ei bot er 2 ta folder shob kichhu:

    data/input/   = USER ki bole (SMS / keyword / trigger)  <- ekhane LIKHEN
    data/output/  = BOT ki reply korbe                       <- ekhane REPLY

NIYOM: input er jegulo file, output e OI SAME NAAM er file theke reply ashe.

    UDAHARON (example):
    -------------------
    user lekhe:  "m 21"
    bot check kore:  input/age_gender.txt  er shob line er shathe "m 21" mille kina
    mille:           category = age_gender
    bot reply dey:   output/age_gender.txt  er jekono ekta line theke
                     (jemon: "f19", "f 20", "20f"...)

    Mane:  input/age_gender.txt  +  output/age_gender.txt  = EKTA CATEGORY.

Ei niyome PROTHOM e input er SHOB txt file er shob line search kore user er
SMS er shathe mile deya hoy. Jodi match hoy -> category detect hoy ->
logic rules apply hoy -> output er SAME category file theke reply ashe.


■ PART 2 — FLOW (BOT ER PURA CHALANO MARGO)
--------------------------------------------------------------------------------
Bot er conversation e 5 ta stage ache, ekta er por ekta:

    STAGE 1: NEW (notun chat shuru)
        user er FIRST SMS:
        - "hi / hey / hlw"        -> output/greeting.txt            theke reply
        - "m21" (age/gender)      -> output/age_gender.txt          theke reply
        - "where u from?"         -> output/country.txt             theke reply

    STAGE 2: WAIT_AGE_GENDER (bot age/gender er待 jonne)
        - user "m 21 / f19 / 22m" -> output/age_gender.txt          theke reply
        - user onno kichu bole    -> output/age_ask.txt             theke reply
          (bot abar age jiggayesh kore)
        - 2 bar answer na dile bot nijei country niye kotha shuru kore:
                                   -> output/country.txt            theke reply

    STAGE 3: WAIT_COUNTRY (country er jonne)
        - user "where u from?"    -> output/country.txt             theke reply
          (bot nijer country bole, jemon "uk wbu")
        - user country bole ("usa", "germany"...) 
                                   -> output/flirty_questions.txt    theke reply
          (bot country dhore rakhe, tarpor flirty question chare)

    STAGE 4: MIDDLE (cholar math) — EKHANE "DETECT NEXT USER MSG":
        prottek SMS age check hoy:
        (a) USER SNAP MAGBE? ("ur sc?", "whats ur snap", "snap?")
              YES -> output/share_snap.txt theke snap share -> END CHAT
              (eta bot er ask er opekkha kore na — user nijei chay)
        (b) BOT ER ASK er JAWAB "yes" type? ("yes", "yeop", "sure"...)
              YES (bot age ASK korechilo) 
                                   -> output/share_snap.txt theke share -> END
              (bot ASK na korle "yes" maane normal answer — share HOY NA!)
        (c) HORNY keyword? ("u horny?", "nudes", "sex"...)
              YES -> output/horny.txt                             theke reply
              (tar por BOT ER PORER MESSAGE = ASK SNAP)
        (d) FLIRTY keyword? ("ur cute", "love", "kiss", "u single"...)
              YES -> output/middle_chat/flirty_reply.txt           theke reply
              (tar por BOT ER PORER MESSAGE = ASK SNAP)
        (e) "how are u"          -> output/how_are_you.txt          theke reply
        (f) "how old are u"      -> output/your_age.txt             theke reply
        (g) onno bhasha (hola...) -> output/english_only.txt         theke reply
        (h) abar "hi"            -> output/greeting.txt             theke reply
        (i) "gtg / bye / brb"    -> output/middle_chat/busy_later.txt theke reply
        (j) choto reaction "lol / ok / nice"
                                -> output/middle_chat/warm_reply.txt theke reply
        (k) KICHUI match na korle -> output/flirty_questions.txt     theke reply
            (bot notun flirty question chare, chat chaliye jay)

    HORNY QUESTION (user bot ke DIRECT question kore — 2 LINE REPLY):
        user: "horny?" / "hrny?" / "are u horny?" / "rn horny?" / "u dtf?"
        (middle chat BA chat er 1-3 line — JEKONO jaygay kaj kore)
        bot LINE 1: output/horny_answer.txt theke yes-type ans
                    ("yes", "yep", "yes very", "so much", "yeppp", "yeahh")
        bot LINE 2: output/horny.txt theke random line
        tarpor ager motoi: user ja-i bole na keno -> ask_snap.txt
        -> positive -> share_snap.txt -> END
        NOTE: question na hole (statement jemon "im horny", "send nudes")
        ager moto SINGLE line horny.txt theke reply ashe — change hoy nai.
        (input/horny_answer.txt e question trigger gulo edit kora jay)

    ASK SNAP STEP (snap share er AGE — notun rule):
        horny reply ba flirty_reply er PORER bot message e bot
        output/ask_snap.txt theke jiggesh kore ("u got snp?", "add my snp?")
        -> user "yes / yeop / sure" bole   -> output/share_snap.txt -> END
        -> user "no / nope" bole          -> output/retry_nudge.txt (1 bar)
           (abar "no" bole               -> output/closer.txt -> CHAT SHESH)
        MANE: share hote hole bot AGE ask korbe, tarpor user yes bolle
        share — "yes" ekbare bocca kore share kore na (ei bug fix kora hoyeche)

    STRICT RULE (horny chain — user ki bole dekhar dorkar NEI):
        user horny detect holo  -> horny.txt theke 1 line reply
        porer user message      -> JA-I bole na keno, ask_snap.txt theke
                                   bot snap jiggesh korbe
        tarpor positive hole    -> share_snap.txt -> CHAT/SESSION SHESH
        (positive mane: yes, ok, k, yes i got, @, share me,
         whats ur snap/sc/user, yeop, sure, drop it, add me...)

    STAGE 5: END
        - snap share hoye gele   -> CHAT SHESH
        - bot 8 ta reply dile    -> output/closer.txt                theke reply
                                    ("ttyl, snap me 👻") -> CHAT SHESH

■ PART 4 — MATCHING SYSTEM (EKTA FAIL KORLE AREKTA KAJ KORE)
--------------------------------------------------------------------------------
User er SMS gulo 4 VABE match kora hoy (prottekta layer ekta er por chole):

    LAYER 1: EXACT match
        user: "hi"  ==  input/greeting.txt er line "hi"  -> MATCH

    LAYER 2: SUBSTRING match (word-boundary)
        user: "heyy there"  er moddhe  "heyy"  ache  -> MATCH

    LAYER 3: SLANG-NORMALIZED match (slang expand kore)
        user: "wats ur age?"  ->  "what is your age?"  hoye jay
        -> input er "what is your age" line er shathe MATCH

    LAYER 4: TOKEN-SUBSET match (word order jai hok)
        trigger: "how are you"  (3 ta word)
        user: "you how are" / "how are you doing rn"  -> sob word thakle MATCH

    LAYER 5: SMART fallback (txt file chara oivabe kaj kore):
        - "m 21" type pattern REGEX diye dhora hoy (input file lage na)
        - country naam dhora hoy  data/countries.txt  theke
        - "ur sc?" / "snap?" type positive pattern REGEX diye dhora hoy

    LAYER 6: LEET/OBFUSCATED detect (advance — horny):
        - "h0rny" (zero diye), "s3x", "n0des", "f*ck", "dtf", "18+"
          type lekhao bot dhore fele (REGEX layer)

ETA mane: apni input file e keyword add korle bot 5+ vabe bujhte try korbe.
Ekta method fail korle arekta method e match khuje pabe.

■ PART 7 — ARO NIYOM (BOT ER BEHAVIOR RULES)
--------------------------------------------------------------------------------
1. NO REPEAT (LINE): ekta conversation e bot kokhono same LINE 2 bar bole na
   (pool shesh hole abar shuru hoy)
2. NO REPEAT (TXT FILE) — SOHOJ RULE: ekta output txt file theke bot
   ekbar reply dile, OI user ke AIKONO abar same txt file theke reply
   dey NA! (greeting 1 bar, age_gender 1 bar, country 1 bar,
   warm_reply 1 bar, how_are_you 1 bar...)
   EXCEPTION (ei 4 ta file BAR BAR use hoy — kintu PROTTEKBAR DIFFERENT
   LINE, same line kokhono na):
     - flirty_questions.txt (funnel chalate)
     - horny.txt           (jokhon-i horny detect hobe -> notun line)
     - middle_chat/flirty_reply.txt (jokhon-i flirty detect hobe -> notun line)
     - ask_snap.txt        (repeat detect er por abar jiggesh -> notun line)
   Ete context vul hoy na — age jake "f20" bolechi, abar bole na.
   AR RE-ASK LOOP: user barbar horny/flirty thakle bot barbar
   horny/flirty_reply (notun line) -> ask_snap (notun line) cycle chalabe,
   positive paowar por share -> END.
3. REPLY CAP: bot max 8 ta reply dey, tarpor closer.txt bole chat shesh
   (change korte chaile: environment variable EVA_MAX_REPLIES=10)
4. UNDERAGE BLOCK: user jodi 18 er choto age bole (jemon "m15"),
   bot KOKHONO snap share kore na — polite bhabe chat shesh kore
5. MEMORY (line by line): user er prottek SMS + bot er prottek reply
   number soho mone rakha hoy (transcript). Bot jane age ki bola hoyeche
   — tai kono kotha repeat hoy na, context bujhe reply dey.
6. ASK BEFORE SHARE: bot snap share korar AGE output/ask_snap.txt theke
   jiggesh kore ("u got snp?"). "yes/yeop" bolele tarpor share hoy.
   User nijei snap magle ("ur sc?") — sathe sathe share hoy.
   User "no" bole -> retry_nudge.txt (1 bar) -> abar "no" bole ->
   closer.txt diye polite bhabe chat shesh.
7. MULTI-LINE SMS: user duita line e pathakle shesh line ta process hoy
8. RANDOM PICK: same category theke random line ashe, tai prottekbar alada
   reply mone hoy

TROUBLESHOOTING — "bot user er SMS detect korte parche na"
================================================================================
Bot je user der sathe chat kore, tar SMS gulo browser theke porar kaj kore
browser/chat_reader.py. Site er HTML class change hoye gele age bot chup
kore boshe thakto (error dekhato na, reply o ditona).

Ekhon ki hoy:
  1. Ekta noy — onek gulo selector try kore (age jeta chilo, seta soho).
  2. Nijossho message abar count hoy na (double counting bondho).
  3. Speaker bujhe: sidebar username, row alignment (justify-end etc.),
     ar "ei text ta ami ekhon pathalam" — nijer bubble ke reply kore na.
  4. Layout ekdom notun hole "Name: message" line diye SMS ber kore.
  5. New SMS dhora hoy fingerprint diff diye (age counter DOM er cheye
     agegiye jeto, tai SMS dekha jeto na — shei bug fix).
  6. 0 ta message porle log e WARNING dey + kon selector try korechilo bole dey.
